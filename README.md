# Blair's Funky Career Islands

**An original retro, top-down, gift-collecting exploration game featuring the professional career of Blair Page.**

Inspired by the *genre and playful exploration mechanics* of classic 1990s console adventures, including surprise presents, wandering hazards, whimsical islands, friendly characters and elevators. **Not affiliated with ToeJam & Earl or its rights holders.** No proprietary artwork, music, character designs, logos, or code are included.

## Play

- Move: **WASD / arrow keys** (on-screen controls on mobile)
- Open a gift when near it: **Space** / **🎁 USE**
- Talk to a mentor, start a technical trial, or use an elevator: **E** / **E TALK**
- Island map: **M** / **ISLAND MAP**
- Close dialogs: **Esc** or **✕**
- Toggle optional synthesized sound from the top navigation.

Collect stars, discover random presents with effects, avoid roaming bugs, restore health, meet career mentors, solve each island's technical trial, and unlock the elevator. Six career islands represent Linux hosting, cloud/IaaS, database engineering, e-commerce, automation, and game-server origins. Recruiter Mode and Achievement Vault link back to Blair's real portfolio.

## Deploy for free on GitHub Pages

1. Create a **public** GitHub repository, suggested name `Blairs-Funky-Career-Islands`.
2. Upload **the contents** of this folder (not the containing folder) to the root of the `main` branch. `index.html` must be in the root.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, then `main` and `/(root)`. Save.
5. Visit `https://blairyfairy.github.io/Blairs-Funky-Career-Islands/` after deployment finishes.

The game uses plain HTML, CSS and JavaScript. There is **no build step, dependency, API key, paid asset, or backend**. You can also upload the static files to itch.io as an HTML5 game.
