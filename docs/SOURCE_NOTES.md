# Source notes

Career content in `data.js` was adapted from the prior Blair's 8-Bit Career Quest repository data, which was based on the supplied Blair Page HTML résumé `index(20261016-133505).html`.

The professional timeline, exact job titles, credential issue dates, education status, and live links should be checked against the latest résumé before publication. No game quest completion, score, or skill rating is presented as an independent employment qualification.

The gameplay is an original implementation. It is stylistically inspired by classic top-down exploration games, not a remake of ToeJam & Earl. Do not add proprietary character art, sounds, maps, logos or music.
